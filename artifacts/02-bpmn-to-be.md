# BPMN TO-BE: Целевой процесс оформления заказа

## Описание
Целевая модель процесса (To-Be), учитывающая ограничения MVP (3 месяца, без переписывания бэкенда с нуля).

## Ключевые изменения
1.  **Гостевой чекаут:** Убрана обязательная регистрация. Пользователь может оформить заказ, указав только Email, Имя, Телефон и Адрес.
2.  **Прозрачная доставка:** Стоимость доставки рассчитывается через API логистики и отображается сразу при выборе способа доставки (до перехода к оплате).
3.  **Ускорение оплаты:** Асинхронная загрузка скриптов платежного шлюза. Внедрение Apple Pay и СБП для минимизации ручного ввода данных.
4.  **Идемпотентность:** На уровне бэкенда внедряется Idempotency-Key для защиты от двойных списаний при повторных кликах или сбоях сети.
